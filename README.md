## Overview

Century Tools gathers company-maintained utilities into one web-based location for internal teams. Rather than requiring a separate application for every utility, employees can use the shared library as a common starting point for workplace resources.

The project is delivered as HTML and is intended to be viewed in a standard modern browser. Organizations can inspect the files, host the collection, and provide access through a straightforward web interface.
